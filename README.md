# 买或租 · 个人住房决策实验室

静态 React / TypeScript / Vite 网页。买来自住或买来出租，从房价和租金开始，按需加入贷款、公积金和费用。默认比较持有满五年后假设成交的资产，区分普通资金、受限公积金和继续持有的房屋权益。原创动漫助手解释结果；无 AI API、账号或财务数据上传。

## 运行与验证

Node.js 22.12+：`npm ci`，`npm run dev`。

验证：`npm test`、`npm run build`、`npm run test:browser`。Windows 浏览器测试使用本机 Edge；其他系统先运行 `npx playwright install chromium`。测试复用127.0.0.1:5173或自行启动服务，截图在被忽略的 `test-results/`。

## 账目口径

两方案起始普通资金、公积金与每月外部预算相同。现金首付不含公积金；全款时实际使用公积金减少所需普通资金。每月先对期初余额计息、加入相同缴存，支付月供/房租，执行公积金安排，再投资现金结余。外部现金预算为两边住房现金支出较大值且不小于0；它用于公平比较住房资产，不代替完整家庭工资预算或月供负担评估。

自住计入省下的住房开销；出租时共同居住租金抵消，另外计入目标房屋收入。净租金可直接填写，或按 `(挂牌月租×年出租月数−年度出租费用)/12` 估算，二者互斥。已扣费用不能重复填入持有费；负净收入表示经营亏损。

本金和公积金提取只是资产转移。公积金使用受余额、对应支出/债务和用户限额约束；提前还款不缩短期限，重算月供。资格是用户提供的假设，出租模式不自动推断双方能用公积金支付共同租金。

卖房净回款 = 预计成交价 − 剩余贷款 − 出售税额 − 出售费用，保留负值。期末普通资金包含净回款，公积金单列；继续持有时保留房屋权益，不扣未发生的出售费。

## 税费政策快照

上海个人普通购入住房，2026-10-20。未来按该情景估算，不预测政策或实际成交资格。

- 不足24个月增值税为含税成交价/1.03×3%；满24个月免征。
- 满60个月且用户确认符合满五唯一全部条件才免个税；默认不确定，按未确认免税估算。
- 原值凭证齐全的个税估算：`max(0, 成交价−增值税−买入价−明确可扣除额−本次附加税)×20%`。可扣除额默认0，不自动认定全部装修/利息可扣。
- 增值税附加综合比例默认12%为占增值税税额的保守试算，非统一税率。符合上海减半条件时可改6%；不将2027年底到期优惠自动延续至未来。
- 手动总税额覆盖自动税额，不叠加。其他地区、核定征收和特殊取得方式请使用自行核实的税额。
- 满二、满五是税收条件，不是限售或成交保证；此模型不涵盖所有税种和特殊交易。

来源：[增值税公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5246356/content.html)、[上海税务不足两年出售说明](https://shanghai.chinatax.gov.cn/xwdt/ztzl/grsx/fwjy/csfclsx/202411/t474236.html)、[上海税费说明](https://www.shanghai.gov.cn/nw17239/20260423/db84274a588149309032977a3df7f916.html)。

## 解释和扫描

贡献图拆解住房开销差、出租收入、价格变化、贷款利息、买入/持有/卖出成本、现金和公积金收益差；合计等于最终总资产差。不是参数因果重要性，不再重复扣机会成本。

扫描逐项测试房价±10%、对应租金±10%、资金收益±0.5个百分点、期末总涨跌幅±10个百分点，显示实际范围并裁剪非法边界。排名只代表该范围的两端结果差异，不是全局重要性或预测；年限不混入排名。

曲线中间按买入价记账，只在所选终点套用价格变化和出售结算，不预测中间价格。终点扣费/价格变化可能出现跳变。

## 补充口径

- 一次性公积金投入勾选「同时从首月按月抵扣」后，月度提取从第1个月开始，不等待未来的一次性投入日期；较早的按月提取可能减少后续一次性投入时的可用余额。
- 买入房价扫描固定期末总涨跌幅百分比，因此期末估值/成交价随买入价同比变化；它不模拟未来售价固定的购入议价。现金投资收益率对应的机会成本已包含在两条路径中，不应再次扣除；居住体验等非财务因素及其他未建模因素不在计算内。
