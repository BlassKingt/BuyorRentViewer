# 买或租 · 第二版设计

用户已确认功能和网页研究助手方向，要求分析后直接开工。保留 React / TypeScript / Vite 静态部署。此版在现有 calculator 中实现，不部署、不操作父目录视频项目。

## 产品
- 名称「买或租」，浅色实验室、青绿与紫蓝、原创成年女性研究员。顶部半身角色，结果区 Q 版助手，点击查看分析手记；可隐藏、关闭动画、尊重 reduced-motion。没有独立窗口、鼠标替换、强制片头或 AI API。
- 核心只填房价与一个租金，默认假设显式显示并可展开修改。自己住 / 出租，自己另租两种用途，住房开销与目标房屋租金独立存储。
- 自住 rent 是继续租房的住房开销；出租 income 是扣空置、出租费用之后，扣房贷之前的平均月净收入。提供直接净额 / 明细估算（挂牌租金、出租月数、年度出租费用），两者互斥。共同居住开销双方抵消。自住可单独查看目标房屋出租收益率但不能增加现金流。避免重复计出租费用与持有费用。
- 资金年化 1.5%，贷款 15 年，商贷预设3%、公积金贷款预设2.6%（可改试算值）；单笔贷款本轮可用，组合贷明确不模拟。普通首付不含公积金；保留公积金余额80000、月缴存2000和留存/月供/一次投入功能。租房提取资格不自动推断。
- 时间成为显式必要假设，默认5年，不再有时间开关。快捷满2/满5/10年，可按月精确调整，比较期与贷款期独立。
- 默认期末出售，显示卖房净回款、现金与受限公积金分别的结果。可选继续持有账面估值。出售价格默认与买入相同，允许调整总涨跌幅；不强行预测增长。
- 起始资金和每月外部预算两边相同；普通现金不得因两边住房成本均为负而出现“负工资预算”，预算下限为0。本金与公积金转移不算损失/收益。净回款为成交价-剩余贷款-卖出税费-中介等费用，不重复扣购房成本。

## 税费
- 标注上海个人普通购入住房、2026-10-20政策快照；未来按该政策情景估算，不预测政策。满2税费与满5唯一不等同限售/保证成交。
- 增值税：持有<24月，含税成交价/1.03*0.03；>=24月免征。
- 个税：>=60月且用户确认满足满五唯一免税条件才免征；默认“不确定”，按未确认免税估算并说明。原值凭证齐全的差额20%估算为 max(0, 不含增值税成交收入-买入价-明确填写的可扣除额-本次附加税)*20%。可扣除额单列，默认0，不把所有装修/利息自动认定可扣。满五唯一这里要求用户确认全部适用条件，不仅名下房数。
- 手动税额模式覆盖自动税额（不是叠加），供其他地区、特殊取得方式、核定征收等场景。自动模式不自由选择1%最优税额。
- 增值税附加按用户可修改的综合比例估算（占增值税额），默认保守12%试算并明确不是统一税率；满足当地减半条件时可改6%，不把2027到期优惠延续到所有未来年份。需核对实际适用地点/日期。值可改。
- 出售中介及其他费用单列，默认成交价1%示例，可改为0；购入和持有额外费用模块保留0但显式标明未填，不假装全部交易税费已覆盖。
- 政策引导放在时间与出售详情旁，显示当前阈值状态，折叠解释/来源/日期。不明限售资格时是有条件估算，不声称实际可立即成交。

## 解释
- 账目贡献（非参数因果归因）：住房开销差、出租净收入、房价变化、贷款利息、买入/持有/卖出费用、现金收益差、公积金收益差。总和必须等于两方案总净资产差；另列现金差与公积金差。
- 参数扫描：固定其他条件，对房价±10%、当前用途相关租金±10%、资金收益±0.5个百分点、出售价格相对买入涨跌±10个百分点逐项重算。必要时裁剪到合法输入，显示实际范围。按影响跨度排名，明确仅在该范围内、非贡献份额、不保证预测。期限不混入此排名。
- 角色使用确定性文案解释当前结果与最大账目项，不接AI；结果无效时不展示旧结论。
